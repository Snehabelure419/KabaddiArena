# KabaddiArena 🏆

KabaddiArena is an Android application developed using Kotlin and Jetpack Compose for managing and analyzing Kabaddi matches and player statistics.

## Features ✨

* Player Profile Management
* Match History Tracking
* Score & Result Screens
* Pie Chart & Statistics Visualization
* Court Screen UI
* Login & Splash Screen
* Notifications Support
* Room Database Integration
* Modern Jetpack Compose UI

## Tech Stack 🛠️

* Kotlin
* Jetpack Compose
* Android Studio
* Room Database
* MVVM Architecture
